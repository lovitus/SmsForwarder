# 二维码离线迁移说明

## 1. 适用场景
- 新旧手机不在同一 WiFi。
- 不方便传输 `SmsForwarder.json` 文件。
- 需要完整离线迁移现有一键克隆配置。

二维码模式位于「一键换新机」页面，与网络模式、离线文件模式并列。

## 2. 旧手机导出
1. 打开「一键换新机」。
2. 切换到「二维码模式」。
3. 点击「生成二维码」。
4. 按弹窗中的上一张/下一张依次展示所有二维码。

实现细节：
- 复用现有 `HttpServerUtils.exportSettings()` 导出的 `CloneInfo`。
- JSON 会先 GZIP 压缩，再 URL-safe Base64 编码。
- 每 500 字符切成一张二维码。
- 每张二维码固定按 512x512 像素生成。
- 二维码不加密，安全级别等同明文 JSON 文件导出。

## 3. 新手机导入
1. 打开「一键换新机」。
2. 切换到「二维码模式」。
3. 点击「扫码导入」。
4. 连续扫描旧手机展示的二维码。
5. 扫齐后自动校验、解压、恢复配置。

导入能力：
- 支持乱序扫码。
- 支持重复扫码去重。
- 支持扫错批次二维码时提示并继续当前批次。
- 收齐后校验 `sessionId`、分片数量、sha256。
- 继续复用现有版本检查 `compareVersion()` 和恢复逻辑 `restoreSettings()`。

## 4. 恢复后必须人工确认
恢复成功后，应用会提示重启。重启后请务必检查：

1. 修改「通用设置」里的设备名称，避免新旧手机名称重复。
2. 检查 Frpc 配置里的端口和代理名，避免与旧设备冲突。
3. 再次核对发送通道、转发规则和自动任务。

应用不会自动修改设备名或 Frpc 配置，避免误改用户已有配置。

## 5. 兼容性说明
- 使用本地 ZXing：
  - `com.google.zxing:core:3.5.3`
  - `com.journeyapps:zxing-android-embedded:3.6.0`
- 不依赖 Google Play Services。
- 不使用 ML Kit。
- 保持 Android 4.4 / API 19 兼容。

## 6. 排错建议
- 提示二维码格式错误：确认扫描的是 SmsForwarder 生成的克隆二维码。
- 提示批次不匹配：继续扫描同一组二维码，不要混用另一台旧手机或另一次生成的二维码。
- 扫码识别困难：调高旧手机屏幕亮度，避免反光，保持二维码完整显示。
- 版本不兼容：新旧手机安装同一版本后再迁移。
